================================================================================
VD5 EDITOR — README
================================================================================

Версия: 1.0
Формат: HTML + JavaScript (один файл)
Назначение: Встраиваемый WYSIWYG-редактор с режимом "только просмотр" по умолчанию
и возможностью включения редактирования только для администратора.

--------------------------------------------------------------------------------
1. ЧТО ЭТО
--------------------------------------------------------------------------------
VD5 Editor — это встраиваемый текстовый редактор (contenteditable), который
изначально работает в режиме ПРОСМОТРА (read-only). Режим редактирования
включается только программно — через внешний флаг (например, если вы
определили, что текущий пользователь — админ).

Редактор поддерживает:
  • форматирование текста (жирный, курсив, подчёркнутый, зачёркнутый, код, маркер)
  • изменение регистра (AA / aA)
  • изменение размера текста
  • вставку таблиц (с добавлением строк/столбцов и удалением)
  • вставку изображений
  • вставку видео с собственными контролами (play/pause, прогресс, громкость, скорость)
  • вставку файлов (с предпросмотром и скачиванием)
  • вставку ссылок (диалоговое окно)
  • drag & drop файлов и внутренних элементов
  • изменение размера и выравнивания медиа-элементов
  • сохранение в localStorage
  • экспорт/импорт в формате .vd5 (JSON)
  • горячие клавиши: Ctrl+S (сохранить), Ctrl+O (открыть .vd5)

--------------------------------------------------------------------------------
2. БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------
1. Скопируйте весь код редактора в один .html файл (или вставьте его в свою
   страницу).
2. Перед закрывающим </body> (или до подключения скрипта редактора) задайте
   глобальный объект конфигурации:

   <script>
     window.VD5_CONFIG = {
       editable: false,                 // по умолчанию — просмотр
       initialContent: '<p>Привет!</p>',
       storageKey: 'my_site_vd5_doc',
       uploadUrl: '/upload',
       onSave: function(state) {
         console.log('Документ сохранён:', state);
       }
     };
   </script>

3. Чтобы включить режим редактирования (например, для админа), вызовите:

   window.VD5Editor.setEditing(true);

   Или сразу при инициализации:

   window.VD5_CONFIG = { editable: true };

--------------------------------------------------------------------------------
3. КОНФИГУРАЦИЯ (window.VD5_CONFIG)
--------------------------------------------------------------------------------
Объект задаётся ДО загрузки скрипта редактора. Все поля опциональны.

  editable        (boolean)  — включить режим редактирования сразу.
                                По умолчанию: false (только просмотр).

  initialContent  (string)   — HTML, который будет показан, если в localStorage
                                нет сохранённого документа.

  storageKey      (string)   — ключ localStorage для автосохранения.
                                Если не задан — автосохранение отключено.
                                По умолчанию: 'vd5_document'.

  uploadUrl       (string)   — URL эндпоинта для загрузки файлов (POST, multipart).
                                Ожидает JSON-ответ: { url, name, size, type }.
                                По умолчанию: '/upload'.

  onSave          (function) — колбэк, вызываемый после сохранения в localStorage.
                                Принимает объект состояния документа:
                                { format, version, savedAt, content }.

Пример:
  window.VD5_CONFIG = {
    editable: false,
    initialContent: '',
    storageKey: 'article_42',
    uploadUrl: '/api/upload',
    onSave: function(state) {
      fetch('/api/save', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(state)
      });
    }
  };

--------------------------------------------------------------------------------
4. API (window.VD5Editor)
--------------------------------------------------------------------------------
После загрузки скрипта доступен глобальный объект window.VD5Editor.

  getHTML()                — вернуть текущий HTML редактора (string).
  setHTML(html)            — установить HTML содержимого.
  getText()                — вернуть текст без разметки (string).
  setText(text)            — установить простой текст.

  isEditing()              — true, если режим редактирования включён.
  setEditing(enabled)      — включить/выключить режим редактирования.
                             enabled = true  → админ может редактировать.
                             enabled = false → только просмотр.

  save()                   — принудительно сохранить в localStorage.
  load()                   — загрузить из localStorage (возвращает boolean).
  downloadVd5()            — скачать текущий документ как .vd5 файл.

  destroy()                — полностью удалить редактор со страницы и снять
                             все обработчики событий.

  element                  — DOM-элемент редактора (#editor).

Примеры:

  // Включить редактирование для админа
  if (currentUser.isAdmin) {
    window.VD5Editor.setEditing(true);
  }

  // Получить содержимое
  const html = window.VD5Editor.getHTML();

  // Загрузить новый документ
  window.VD5Editor.setHTML('<h1>Новая статья</h1><p>Текст...</p>');

  // Сохранить вручную
  window.VD5Editor.save();

  // Скачать .vd5
  window.VD5Editor.downloadVd5();

--------------------------------------------------------------------------------
5. ВСТРАИВАНИЕ В САЙТ
--------------------------------------------------------------------------------
Рекомендуемый способ — вставить редактор в отдельный контейнер на странице.

Минимальный пример:

  <!DOCTYPE html>
  <html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>
      /* Стили редактора уже включены в сам файл, но можно переопределить */
    </style>
  </head>
  <body>
    <!-- Сюда будет встроен редактор -->
    <div id="editor-mount"></div>

    <script>
      window.VD5_CONFIG = {
        editable: false,
        storageKey: 'page_about',
        uploadUrl: '/upload',
        initialContent: '<p>Добро пожаловать!</p>'
      };
    </script>

    <!-- Вставьте сюда весь код редактора (HTML + <script>) -->

    <script>
      // Пример: включить редактирование, если пользователь — админ
      const user = { isAdmin: true }; // получите откуда-то извне
      if (user.isAdmin) {
        window.VD5Editor.setEditing(true);
      }
    </script>
  </body>
  </html>

ВАЖНО: редактор использует position: fixed для сайдбара и тулбаров,
поэтому лучше размещать его на отдельной странице или в iframe, если
вы встраиваете его в сложный layout.

--------------------------------------------------------------------------------
6. ФОРМАТ .VD5
--------------------------------------------------------------------------------
Файл .vd5 — это обычный JSON:

  {
    "format": "vd5",
    "version": 1,
    "savedAt": "2025-01-01T12:00:00.000Z",
    "content": "<p>HTML содержимое редактора</p>"
  }

Импорт: кнопка "Открыть .vd5" в сайдбаре или Ctrl+O.
Экспорт: кнопка "Сохранить .vd5" в сайдбаре или window.VD5Editor.downloadVd5().

--------------------------------------------------------------------------------
7. ЗАГРУЗКА ФАЙЛОВ
--------------------------------------------------------------------------------
Редактор отправляет файлы POST-запросом (multipart/form-data) на uploadUrl.
Поле формы: "file".

Ожидаемый ответ (JSON):

  {
    "url": "/uploads/image_123.png",
    "name": "image.png",
    "size": 123456,
    "type": "image/png"
  }

Если сервер вернёт другой формат — поправьте функцию uploadFileToServer()
в коде редактора.

--------------------------------------------------------------------------------
8. ГОРЯЧИЕ КЛАВИШИ (только в режиме редактирования)
--------------------------------------------------------------------------------
  Ctrl+S / Cmd+S  — сохранить в localStorage
  Ctrl+O / Cmd+O  — открыть .vd5 файл

--------------------------------------------------------------------------------
9. БЕЗОПАСНОСТЬ
--------------------------------------------------------------------------------
  • По умолчанию редактор работает в режиме ПРОСМОТРА — пользователь не может
    ничего изменить.
  • Режим редактирования включается ТОЛЬКО программно через
    window.VD5Editor.setEditing(true) — то есть вы контролируете это извне
    (проверка авторизации, роли и т.п.).
  • contenteditable="true" устанавливается только при включении редактирования.
  • Все вставки файлов идут через ваш сервер (uploadUrl) — вы контролируете
    валидацию и хранение.
  • HTML не санитизируется на клиенте — если вы принимаете контент от
    недоверенных пользователей, санитизируйте его на сервере перед сохранением.

--------------------------------------------------------------------------------
10. УСТРАНЕНИЕ НЕПОЛАДОК
--------------------------------------------------------------------------------
Проблема: редактор не появляется / пустой.
  → Убедитесь, что скрипт редактора загружен ПОСЛЕ элемента #editor в DOM
    (или используйте defer / размещение перед </body>).

Проблема: кнопки не работают.
  → Проверьте, что режим редактирования включён:
    window.VD5Editor.isEditing() === true.

Проблема: файлы не загружаются.
  → Проверьте uploadUrl и формат ответа сервера (см. раздел 7).

Проблема: настройки не применяются.
  → window.VD5_CONFIG должен быть задан ДО загрузки скрипта редактора.

Проблема: контент не сохраняется.
  → Проверьте, что storageKey задан в конфиге.

--------------------------------------------------------------------------------
11. ЛИЦЕНЗИЯ / ИСПОЛЬЗОВАНИЕ
--------------------------------------------------------------------------------
Используйте как угодно. Файл самодостаточный, без внешних зависимостей,
кроме SVG-иконок, которые подгружаются из /data/*.svg (если их нет —
автоматически используются встроенные SVG-заглушки).

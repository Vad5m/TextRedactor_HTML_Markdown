# VD5 Editor

Встраиваемый WYSIWYG-редактор. По умолчанию — только просмотр. Редактирование включается программно (например, для админа). Один HTML-файл, без зависимостей.

## Что умеет

- Форматирование: жирный, курсив, подчёркнутый, зачёркнутый, код, маркер
- Размер текста, регистр
- Таблицы (добавление/удаление строк и столбцов)
- Изображения, видео (свои контролы: play/pause, прогресс, громкость, скорость), файлы с предпросмотром, ссылки
- Drag & drop файлов и внутренних элементов
- Ресайз и выравнивание медиа
- Undo/Redo (кнопки справа сверху + Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y)
- Автосохранение в localStorage
- Экспорт/импорт `.vd5` (JSON)
- Ctrl+S — сохранить, Ctrl+O — открыть `.vd5`

## Быстрый старт

1. Вставь весь код в один `.html`.
2. До подключения скрипта задай конфиг:

```html
<script>
  window.VD5_CONFIG = {
    editable: false,
    initialContent: '<p>Привет!</p>',
    storageKey: 'my_site_vd5_doc',
    uploadUrl: '/upload',
    onSave: function(state) { console.log(state); }
  };
</script>
